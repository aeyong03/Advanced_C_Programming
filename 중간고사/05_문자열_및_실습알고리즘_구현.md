# 🔤 Part 4. 문자열 처리 및 실습 알고리즘 구현

## 1. C언어 문자열의 핵심 문법 규칙

### (1) 널 문자(`\0`, ASCII 0)의 절대적 중요성
- C언어에는 별도의 독립된 문자열(string) 타입이 없으며, **문자 배열의 끝에 `\0`이 들어있는 형태**로 문자열을 표현합니다.
- `char str[6] = "hello";` ➔ 실제 저장되는 글자는 `'h', 'e', 'l', 'l', 'o', '\0'` 총 6개.
- 문자열을 동적 할당할 때는 항상 **`strlen(s) + 1`** 바이트를 할당해야 합니다.

---

### (2) ⚠️ 시험 빈출 함정: 문자열 포인터 vs 문자열 배열
```c
char str1[] = "Hello"; // 문자 배열 (스택 영역에 복사됨)
char *str2 = "Hello";  // 문자열 리터럴 포인터 (상수/코드 영역 가리킴)

str1[0] = 'h'; // (O) 가능! 정상적으로 "hello"로 변경됨
str2[0] = 'h'; // (X) 컴파일은 되나 실행 시 런타임 Crash! (Access Violation)
```
- `"Hello"`와 같은 **문자열 리터럴은 읽기 전용(Read-Only) 메모리**에 저장됩니다.
- 따라서 `char *` 포인터로 리터럴을 직접 가리키고 값을 수정하려고 하면 운영체제가 세그멘테이션 폴트(Segmentation Fault)를 일으킵니다.

## 2. 문자열 표준 함수 직접 구현 (03강 실습 1 과제)

교수님께서 라이브러리 함수(`string.h`) 없이 구현하는 실습을 진행하셨으므로, 빈칸이나 코드 작성 문제로 출제될 확률이 매우 높습니다.

### (1) `my_strlen` (문자열 길이 계산)
```c
int my_strlen(const char *s) {
    int len = 0;
    while (*s != '\0') { // 널 문자를 만날 때까지 반복
        len++;
        s++;             // 다음 문자로 포인터 이동
    }
    return len;
}
```

### (2) `my_strcpy` (문자열 복사)
```c
void my_strcpy(char *dest, const char *src) {
    while (*src != '\0') {
        *dest = *src;    // 원본 값을 대상에 복사
        dest++;
        src++;
    }
    *dest = '\0';        // 🔥 반드시 마지막에 널 문자를 닫아주어야 함!
}
```

### (3) `my_strcat` (문자열 이어붙이기)
```c
void my_strcat(char *dest, const char *src) {
    // 1단계: dest의 기존 끝('\0') 위치로 이동
    while (*dest != '\0') {
        dest++;
    }
    // 2단계: 그 위치부터 src 문자들을 순서대로 복사
    while (*src != '\0') {
        *dest = *src;
        dest++;
        src++;
    }
    *dest = '\0'; // 널 문자 추가
}
```

### (4) `my_strcmp` (문자열 대소 비교)
```c
int my_strcmp(const char *s1, const char *s2) {
    while (*s1 != '\0' && *s1 == *s2) {
        s1++;
        s2++;
    }
    if (*s1 > *s2) return 1;
    else if (*s1 < *s2) return -1;
    else return 0;
}
```

### (5) 대소문자 무시 비교 (05강 실습 1)
```c
int my_stricmp(const char *s1, const char *s2) {
    while (*s1 != '\0' && *s2 != '\0') {
        char c1 = (*s1 >= 'A' && *s1 <= 'Z') ? (*s1 + 32) : *s1;
        char c2 = (*s2 >= 'A' && *s2 <= 'Z') ? (*s2 + 32) : *s2;
        if (c1 != c2) {
            return (c1 > c2) ? 1 : -1;
        }
        s1++;
        s2++;
    }
    return (*s1 == '\0' && *s2 == '\0') ? 0 : ((*s1 != '\0') ? 1 : -1);
}
```

## 3. 강의자료 핵심 실습 알고리즘 분석

### (1) 에라토스테네스의 체 (03강 실습 4)
- **원리**: 2부터 시작하여 아직 지워지지 않은 수의 배수들을 차례대로 `0`으로 치환.
- **인덱스 매핑 주의**: 숫자는 `2 ~ 30`인데 배열 크기는 29칸(`arr[0] ~ arr[28]`)이므로, 숫자 `a`의 인덱스는 **`a - 2`**가 됨!
```c
void my_eratosthenes(int arr[]) {
    int a, b;
    for (a = 2; a <= 30; a++) {
        if (arr[a - 2] != 0) { // 소수일 경우
            for (b = a + a; b <= 30; b += a) {
                arr[b - 2] = 0; // a의 배수를 0으로 지움
            }
        }
    }
}
```

### (2) 문자열 세로로 읽기 (05강 실습 3)
- 여러 행의 문자열 길이가 서로 다를 때, `j`번째 열 문자가 존재하는지 체크(`str[i][j] != '\0'`)하고 건너뛰는 알고리즘.
```c
void print_vertical(char **lines, int n, int max_len) {
    for (int col = 0; col < max_len; col++) {
        for (int row = 0; row < n; row++) {
            if (col < strlen(lines[row])) {
                putchar(lines[row][col]);
            }
        }
    }
    printf("\n");
}
```

## 🔍 4. 시험 대비 빈칸 & 오류 찾기 & O/X 체크리스트

### [유형 1: O / X 퀴즈]
1. `char *p = "Kwangwoon"; p[0] = 'k';`는 문법적으로 완벽하며 정상 실행된다.
   - **정답: X**
   - **해설**: `"Kwangwoon"`은 문자열 리터럴(Read-Only 데이터)이므로 수정 시도시 런타임 오류(Segmentation fault)가 발생합니다.

2. `char s[10] = "abc";` 일 때 `sizeof(s)`의 값은 `4`이다.
   - **정답: X**
   - **해설**: `strlen(s)`는 3이고, `sizeof(s)`는 배열 전체 크기인 `10`입니다.

3. `strcpy` 함수로 문자열을 복사할 때 목적지 배열의 크기가 원본 문자열 길이보다 작아도 컴파일 타임에 자동으로 에러를 잡아준다.
   - **정답: X**
   - **해설**: C 컴파일러는 배열 경계 검사(Bounds Check)를 하지 않으므로 버퍼 오버플로우(Buffer Overflow)가 발생하여 프로그램이 비정상 종료됩니다.

---

### [유형 2: 코드 오류 찾기 및 수정]
**[문제] 두 문자열을 이어붙이는 `strcat` 함수이다. 치명적인 오류가 있는 줄을 찾고 수정하시오.**
```c
01 void my_strcat(char *dest, char *src) {
02     while (*dest != '\0') dest++;
03     while (*src != '\0') {
04         *dest = *src;
05         dest++;
06         src++;
07     }
08 }
```
- **오류 분석 및 수정**:
  - **08행 추가**: `*dest = '\0';`
  - 원본 문자열을 복사한 후 끝에 널 문자(`\0`)를 붙여주지 않으면 문자열의 끝을 인식하지 못해 가비지 데이터가 출력되는 치명적 버그가 발생합니다.
