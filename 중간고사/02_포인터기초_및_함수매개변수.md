# 📘 Part 1. 포인터 기초 및 함수 매개변수 완벽 분석

## 1. 메모리와 주소(Address)의 본질

### (1) 바이트(Byte) 단위 주소 체계
- 컴퓨터 메모리는 **1바이트(8비트) 단위**로 고유한 번지수(주소, Address)를 할당받습니다.
- 데이터 타입마다 점유하는 크기가 다릅니다:
  - `char`: 1바이트
  - `short`: 2바이트
  - `int`, `long`, `float`: 4바이트
  - `double`, `long long`: 8바이트
  - **포인터 변수의 크기**: 시스템 아키텍처에 따름 (32비트 환경에서는 **4바이트**, 64비트 환경에서는 **8바이트**). 강의 슬라이드 기준 기본 설명은 **4바이트**를 기준으로 설명함.
- **변수의 시작 주소**: 여러 바이트를 차지하는 변수의 주소는 항상 **가장 낮은 시작 번지(첫 번째 바이트의 번지)**를 나타냅니다.

## 2. 핵심 연산자: `&`와 `*`

| 연산자 | 명칭 | 기능 | 예시 |
| :---: | :---: | :--- | :--- |
| `&` | **주소 연산자** (Address-of) | 피연산자의 메모리 시작 주소를 구함 | `p = &a;` (`a`의 주소를 `p`에 대입) |
| `*` | **역참조 연산자** (Dereference) | 포인터가 가리키는 주소에 저장된 실제 메모리 값에 접근/수정 | `*p = 100;` (`p`가 가리키는 곳에 100 저장) |

### ⚠️ 주의: `*`의 두 가지 문법적 의미
1. **선언문에서의 `*`**: "이 변수는 포인터 변수다"라는 **타입 수식어**
   ```c
   int *p; // int형 변수의 주소를 담는 포인터 변수 p 선언
   ```
2. **실행문에서의 `*`**: "이 주소에 들어있는 값을 읽거나 쓰겠다"는 **역참조 연산자**
   ```c
   *p = 20; // p가 가리키는 메모리 공간에 20을 대입
   ```

### 💡 핵심 공식
$$*(\&a) \equiv a$$
- `&a`로 주소를 구한 뒤, 다시 `*`로 역참조하면 원래 변수 `a` 자신이 됩니다.

## 3. 배열과 포인터의 관계: "포인터 상수" vs "포인터 변수"

### (1) 배열 이름의 본질: "포인터 상수 (Pointer Constant)"
- `int arr[5];` 선언 시, `arr`은 메모리에 할당된 연속된 공간의 **첫 번째 원소 주소(`&arr[0]`)**를 값으로 갖습니다.
- **포인터 상수**이므로 주솟값을 다른 곳으로 변경할 수 없습니다 (L-value가 될 수 없음).
  ```c
  int arr[5];
  int *p;
  
  p = arr;     // (O) 가능 (포인터 변수에 주소 복사)
  arr = p;     // (X) 컴파일 에러! (배열 이름은 상수이므로 대입 불가)
  arr++;       // (X) 컴파일 에러! (arr = arr + 1 불가)
  p++;         // (O) 가능 (포인터 변수는 이동 가능)
  ```

### (2) 포인터 연산의 스케일링 규칙 (매우 중요)
- 포인터에 정수를 더하거나 뺄 때, **실제 증가/감소하는 바이트 수 = `정수 × sizeof(*p)`**
  ```c
  int *p = (int*)1000;
  p + 1  // 실제 주소: 1000 + 1 * 4 = 1004번지
  p + 3  // 실제 주소: 1000 + 3 * 4 = 1012번지
  
  char *cp = (char*)1000;
  cp + 1 // 실제 주소: 1000 + 1 * 1 = 1001번지
  ```

### (3) 배열 첨자 연산자 `[]`와 포인터 연산의 완전 동일성
컴파일러는 `arr[i]`를 내부적으로 다음과 같이 치환하여 처리합니다:
$$\mathbf{arr[i] \Longleftrightarrow *(arr + i) \Longleftrightarrow *(i + arr) \Longleftrightarrow i[arr]}$$
$$\mathbf{\&arr[i] \Longleftrightarrow arr + i}$$

> **[심화 디테일]** C언어에서는 `i[arr]`도 완벽히 유효한 문법입니다! `*(i + arr)`로 교환법칙이 성립하기 때문입니다.

## 4. 함수와 포인터: 매개변수 전달 방식

### (1) 값에 의한 호출 (Call by Value)
- 인자로 넘어간 변수의 **'값(복사본)'**만 함수 매개변수에 복사됩니다.
- 함수 내부에서 매개변수를 아무리 수정해도 **호출자(caller)의 원본 변수에는 전혀 영향이 없습니다.**
```c
void swap_fail(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
} // 함수 종료 시 a, b는 스택에서 소멸! 원본은 그대로
```

### (2) 주소에 의한 호출 (Call by Reference / Address)
- 인자로 원본 변수의 **'주소(`&`)'**를 넘깁니다.
- 매개변수는 **포인터 변수(`*`)**로 선언되어 주소를 받고, 내부에서 **역참조 연산자(`*`)**를 통해 원본 메모리를 직접 조작합니다.
```c
void swap_success(int *a, int *b) {
    int temp = *a;  // a가 가리키는 원본 값을 임시 저장
    *a = *b;        // b가 가리키는 원본 값을 a가 가리키는 원본에 복사
    *b = temp;      // 임시 저장된 값을 b가 가리키는 원본에 복사
}

int main() {
    int x = 10, y = 20;
    swap_success(&x, &y); // 주소를 전달!
    // x = 20, y = 10으로 실제 변경됨
}
```

### (3) 배열을 함수 인자로 전달할 때의 Decay 현상 (시험 단골 함정!)
```c
void print_size(int arr[100]) {
    printf("%zu\n", sizeof(arr)); // 100 * 4 = 400바이트가 아님!!
}
```
- 배열이 함수의 매개변수로 선언되면 컴파일러는 이를 무조건 **`int *arr` (포인터 변수)**로 취급(Decay)합니다.
- 따라서 함수 내부에서 `sizeof(arr)`의 결과는 **배열 전체 크기가 아니라 포인터 변수 크기(4바이트 또는 8바이트)**가 출력됩니다!
- **올바른 사용법**: 배열을 함수로 넘길 때는 반드시 **배열의 크기(size/count)**를 별도의 매개변수로 함께 넘겨주어야 합니다.
  ```c
  void print_array(int *arr, int size);
  ```

## 🔍 5. 시험 대비 빈칸 & 오류 찾기 & O/X 체크리스트

### [유형 1: O / X 퀴즈]
1. `int a = 10; int *p = a;`
   - **정답: X (오류)**
   - **해설**: `p`는 주소를 담는 변수이므로 `a`의 주소인 `&a`를 대입해야 합니다. 정수 `10`을 주소로 강제 대입하려고 하므로 컴파일 경고 또는 에러가 발생합니다.

2. `int arr[3] = {1, 2, 3}; arr++;`
   - **정답: X (오류)**
   - **해설**: `arr`은 포인터 상수이므로 증감 연산자(`++`, `--`)의 피연산자가 될 수 없습니다.

3. `int arr[5];` 일 때 `arr + 2`의 값과 `&arr[2]`의 값은 동일하다.
   - **정답: O (맞음)**
   - **해설**: `arr + 2`는 2번 인덱스의 주소이며, `&arr[2]`와 완전히 일치합니다.

### [유형 2: 코드 오류 찾기 및 수정]
**[문제] 두 정수의 값을 바꾸려는 다음 코드에서 오류가 있는 줄을 찾고 올바르게 수정하시오.**
```c
01 void swap(int a, int b) {
02     int temp = a;
03     a = b;
04     b = temp;
05 }
06 int main() {
07     int x = 10, y = 20;
08     swap(x, y);
09     return 0;
10 }
```
- **오류 분석 및 수정**:
  - 01행 수정: `void swap(int *a, int *b)` (매개변수를 포인터로 변경)
  - 02~04행 수정: `int temp = *a; *a = *b; *b = temp;` (역참조 연산자 `*` 추가)
  - 08행 수정: `swap(&x, &y);` (주소 연산자 `&`를 붙여 인자 전달)

### [유형 3: 빈칸 완성형]
**[문제] 배열의 모든 원소의 합을 포인터 연산을 통해 구하는 반복문의 빈칸을 채우시오.**
```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;
int hap = 0;
for (int i = 0; i < 5; i++) {
    hap += ____________; // 빈칸
}
```
- **정답**: `*(p + i)` 또는 `p[i]` 또는 `*(arr + i)`
