## 1. 표준 입출력 (Standard I/O)

### 1.1 개요
- **표준 입력(`stdin`)**: 기본 입력 스트림으로 기본 장치는 **키보드**.
- **표준 출력(`stdout`)**: 기본 출력 스트림으로 기본 장치는 **모니터/콘솔**.
- **표준 에러(`stderr`)**: 에러 출력 스트림(버퍼링 없음).

---

### 1.2 문자열 입출력 함수 및 `scanf` 주의점

| 함수 | 특징 및 사용법 | 장점 및 주의사항 |
| :--- | :--- | :--- |
| `scanf("%s", buf)` | 공백(스페이스, 탭, 개행) 직전까지만 단어 단위로 입력 | 입력 버퍼에 개행 문자(`\n`) 등이 그대로 남아있어 다음 입력에 영향 |
| `gets_s(buf, sizeof(buf))` | Enter(`\n`)가 입력될 때까지 공백 포함 한 줄 전체를 읽음 | 읽어들인 `\n`을 널 문자(`\0`)로 자동 변환하여 저장. 버퍼 오버플로우 방지 |
| `puts(buf)` | 문자열 출력 후 **자동으로 개행(`\n`)** 수행 | `printf("%s\n", buf)`보다 속도가 빠르고 간결 |

#### 🔥 시험/실습 빈출 함정: `scanf("%s")` 후 `%c` 사용 시 버퍼 문제
- **현상**:
  ```c
  char str[20];
  char ch;
  scanf("%s", str); // 사용자가 "hello" 입력 후 Enter 치면 '\n'이 입력 버퍼에 남음
  scanf("%c", &ch);  // %c는 공백/개행을 건너뛰지 않으므로 남아있던 '\n'이 ch에 들어가버림!
  ```
- **해결책**:
  1. `%c` 앞에 공백 하나를 추가: `scanf(" %c", &ch);` (공백/개행을 무시하고 실제 문자 입력 대기)
  2. 한 줄 단위 입력 시 `gets_s(str, sizeof(str))` 사용.

---

### 1.3 문자 입출력 함수 비교 (`getchar`, `getch`, `getche`)

| 함수 | 헤더 | 에코(Echo) 여부 | 버퍼(Buffer) 사용 여부 | 특징 및 용도 |
| :--- | :--- | :--- | :--- | :--- |
| `getchar()` | `<stdio.h>` | **O** (화면 표시) | **O** (Enter 칠 때까지 버퍼링) | 표준 함수. 한 번에 여러 글자 치고 Enter 누르면 차례로 1문자씩 반환 |
| `putchar(c)` | `<stdio.h>` | - | 표준 출력 | 문자 1개를 화면에 출력 |
| `getch()` | `<conio.h>` | **X** (화면 미표시) | **X** (즉시 입력 반환) | 비밀번호 입력 화면(별표 `*` 표시), 콘솔 키 입력 시 주로 사용 |
| `getche()` | `<conio.h>` | **O** (화면 즉시 표시) | **X** (즉시 입력 반환) | Enter 없이 키를 누르자마자 즉시 모니터에 찍히고 반환 (Echo) |
| `putch(c)` | `<conio.h>` | - | 즉시 콘솔 출력 | 콘솔에 1문자 직접 출력 |

#### 💡 `getchar()`의 버퍼 동작 원리 예시
사용자가 `ab[Enter]`를 입력했을 때:
1. 입력 버퍼에는 `'a'`, `'b'`, `'\n'` 3개의 문자가 들어감.
2. 1번째 `getchar()` 호출 $\rightarrow$ `'a'` 반환
3. 2번째 `getchar()` 호출 $\rightarrow$ `'b'` 반환
4. 3번째 `getchar()` 호출 $\rightarrow$ `'\n'` 반환

## 2. 파일 입출력 (File I/O) 기본

### 2.1 파일 입출력 4단계 프로세스
```c
#include <stdio.h>

int main(void) {
    // 1단계: 파일 포인터 선언
    FILE *fp;

    // 2단계: fopen()으로 파일 열기 및 실패 검사 (필수!)
    fp = fopen("C:\\temp\\data.txt", "rt");
    if (fp == NULL) {
        printf("파일 열기 실패!\n");
        return -1;
    }

    // 3단계: 파일 처리 (읽기 또는 쓰기)
    // fgets, fputs, fscanf, fprintf 등 수행

    // 4단계: fclose()로 파일 닫기 (메모리 버퍼 비우기 및 자원 반환)
    fclose(fp);
    return 0;
}
```

### 2.2 파일 오픈 모드 정리

| 모드 | 파일이 있을 때 | 파일이 없을 때 | 주요 설명 |
| :--- | :--- | :--- | :--- |
| `"r"` / `"rt"` | 정상 열기 | **에러 (`NULL` 반환)** | 읽기 전용 (Read) |
| `"w"` / `"wt"` | **기존 내용 삭제(Overwrite)** | **새 파일 생성** | 쓰기 전용 (Write) |
| `"a"` / `"at"` | 파일 맨 끝에 내용 추가 (Append) | **새 파일 생성** | 추가 모드 |
| `"rb"`, `"wb"` | 바이너리 모드로 동작 | 위와 동일 | 텍스트 변환(`\r\n` $\leftrightarrow$ `\n`) 없이 원본 바이트 그대로 입출력 |

> **⚠️ 파일 경로 주의사항**:  
> C 언어 문자열에서 `\`는 특수문자(Escape sequence)입니다.  
> 윈도우 경로 표현 시 반드시 `\\` (두 개)를 쓰거나 `/` (슬래시)를 사용해야 합니다.  
> 예: `"C:\\temp\\data1.txt"` 또는 `"C:/temp/data1.txt"`

## 3. 주요 파일 입출력 함수

### 3.1 `fgets()` 와 `fputs()` (문자열 입출력)
- **`fgets(char *str, int size, FILE *stream)`**:
  - 개행 문자(`\n`)를 만날 때까지 또는 최대 `size - 1`개의 문자를 읽음.
  - **중요**: `gets_s()`와 달리 **`\n` 문자도 버퍼 끝에 포함**시켜 저장하고 마지막에 `\0`을 붙임!
  - 파일 끝(EOF)에 도달하거나 실패 시 `NULL`을 반환.
- **`fputs(const char *str, FILE *stream)`**:
  - `puts()`와 달리 **자동으로 `\n`을 붙이지 않음**. 사용자가 직접 개행을 제어해야 함.

```c
// DOS의 'type' 명령어 구현 예시 (파일 내용을 콘솔에 출력)
FILE *fp = fopen("data.txt", "rt");
char buffer[256];
if (fp != NULL) {
    while (fgets(buffer, sizeof(buffer), fp) != NULL) {
        printf("%s", buffer); // buffer에 이미 \n이 포함되어 있음
    }
    fclose(fp);
}
```

### 3.2 `fscanf()` 와 `fprintf()` (서식화 입출력)
- **`fscanf(FILE *stream, const char *format, ...)`**:
  - 파일로부터 정수, 실수, 공백 없는 문자열 등을 서식에 맞추어 읽어들임.
  - 성공적으로 매칭되어 읽힌 인자의 개수를 반환하며, 파일 끝에서는 `EOF`(-1)를 반환.
- **`fprintf(FILE *stream, const char *format, ...)`**:
  - `printf`와 동일한 방식으로 파일에 서식화된 문자열을 출력.

---

### 3.3 `feof()` 올바른 사용 패턴
- `feof(fp)`는 파일의 끝을 읽으려고 시도한 후 EOF 표식이 설정되어야 비로소 참(0이 아닌 값)을 반환합니다.
- **권장 패턴**:
  ```c
  // 방법 1: fscanf 반환값 직접 검사 (가장 안전)
  while (fscanf(fp, "%s %d", name, &age) == 2) {
      // 정상 처리
  }

  // 방법 2: fgets 반환값 직접 검사
  while (fgets(line, sizeof(line), fp) != NULL) {
      // 정상 처리
  }
  ```

## 4. 중간고사 리뷰 & 포인터 핵심 연계 (07강)

### 4.1 2차원 배열 포인터 연산 원리
> `int matrix[3][4];` 일 때, `*(matrix + 2) + 1 == &matrix[2][1]` 은 **True or False?** $\rightarrow$ **True!**

1. `matrix`는 각 행(크기 4인 int 배열)을 가리키는 포인터 역할을 하므로 `matrix + 2`는 2행의 시작 주소 `&matrix[2]`를 의미.
2. `*(matrix + 2)`를 역참조하면 `matrix[2]` (2행 배열 자체)가 됨.
3. 배열 이름 `matrix[2]`는 수식 내에서 첫 번째 원소의 주소 `&matrix[2][0]`으로 평가됨.
4. 따라서 `*(matrix + 2) + 1`은 `&matrix[2][0] + 1`이 되어 `&matrix[2][1]`과 정확히 일치함!

---

### 4.2 포인터 배열 동적 메모리 할당 오류와 수정

#### 잘못된 코드 (주소가 아닌 정수 값을 대입한 오류):
```c
int *ptr_array[3]; // 포인터를 담는 배열 (각 원소가 int*)
for (int aa = 0; aa < 3; aa++) {
    ptr_array[aa] = aa; // ❌ 경고/오류: 정수값 aa를 포인터 변수에 직접 넣음 (잘못된 메모리 주소 참조)
}
for (int bb = 0; bb < 3; bb++) {
    printf("%d", *ptr_array[bb]); // ❌ 잘못된 주소 역참조로 Segmentation Fault(런타임 에러) 발생!
}
```

#### 올바른 해결 방법:
- **1안 (지역 변수 주소 대입 시 주의)**:
  `ptr_array[aa] = &aa;`  
  $\rightarrow$ 문법적 컴파일 에러는 없으나, 모든 원소가 동일한 변수 `aa`의 주소를 가리키므로 루프 종료 후 출력하면 마지막 값인 `3 3 3`이 출력되는 논리 오류 발생!
- **2안 (동적 할당 - 정석 해법)**:
  ```c
  int *ptr_array[3];
  for (int aa = 0; aa < 3; aa++) {
      ptr_array[aa] = (int *)malloc(sizeof(int)); // 힙 영역에 각 정수 공간 개별 할당
      *ptr_array[aa] = aa;                         // 할당된 공간에 값 저장
  }
  for (int bb = 0; bb < 3; bb++) {
      printf("%d ", *ptr_array[bb]);              // 0 1 2 정상 출력
  }
  // 사용 후 메모리 해제 필수!
  for (int i = 0; i < 3; i++) {
      free(ptr_array[i]);
  }
  ```

## 5. 실전 실습 과제 구현 및 코드 분석

### [실습 1] 구구단 파일 출력 (`fprintf`)
- **요구사항**: 사용자로부터 단을 입력받아 `x_dan.txt` 파일에 구구단 결과를 저장.
```c
#include <stdio.h>

int main(void) {
    int num;
    printf("출력할 단 입력 : ");
    if (scanf("%d", &num) != 1) return -1;

    char filename[20] = "0_dan.txt";
    filename[0] = num + '0'; // 단 번호를 파일 이름에 반영

    FILE *fp = fopen(filename, "w"); // "w": 파일이 없으면 새로 생성
    if (fp == NULL) return -1;

    for (int i = 1; i <= 9; i++) {
        fprintf(fp, "%d X %d = %d\n", num, i, num * i);
    }

    fclose(fp);
    printf("%s 파일 저장 완료\n", filename);
    return 0;
}
```

### [실습 2] 평점 계산기 (`fscanf`, `grade.txt`)
- **요구사항**: `grade.txt`로부터 과목명, 학점, 성적(A+, A0 등)을 읽어 과목별 점수(학점 $\times$ 성적)와 총평점(총점 / 총학점) 계산.
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    FILE *fp = fopen("grade.txt", "rt");
    if (fp == NULL) {
        printf("grade.txt 파일 열기 실패\n");
        return -1;
    }

    char subject[50];
    int credit;
    char grade[5];
    double total_score = 0.0;
    int total_credit = 0;

    printf("과목명\t\t과목별 점수\n");
    printf("---------------------------\n");

    char header[100];
    fgets(header, sizeof(header), fp); // 첫 행 헤더 건너뛰기

    while (fscanf(fp, "%s %d %s", subject, &credit, grade) == 3) {
        double score = 0.0;
        if (strcmp(grade, "A+") == 0) score = 4.5;
        else if (strcmp(grade, "A0") == 0) score = 4.0;
        else if (strcmp(grade, "B+") == 0) score = 3.5;
        else if (strcmp(grade, "B0") == 0) score = 3.0;
        else if (strcmp(grade, "C+") == 0) score = 2.5;
        else if (strcmp(grade, "C0") == 0) score = 2.0;
        else if (strcmp(grade, "D+") == 0) score = 1.5;
        else if (strcmp(grade, "D0") == 0) score = 1.0;
        else score = 0.0;

        double subject_score = credit * score;
        printf("%s\t\t%.1f\n", subject, subject_score);

        total_score += subject_score;
        total_credit += credit;
    }

    if (total_credit > 0) {
        printf("---------------------------\n");
        printf("총 평점 : %.2f\n", total_score / total_credit);
    }

    fclose(fp);
    return 0;
}
```

### [실습 3] POS기 프로그램 (`menu.txt`, `atoi`, 동적 할당, `receipt.txt`)
- **요구사항**: `menu.txt`에서 메뉴와 가격을 읽어 목록 표시 $\rightarrow$ 0번 누를 때까지 복수 선택 $\rightarrow$ 동적 메모리 할당 및 포인터 배열에 저장 $\rightarrow$ `receipt.txt`에 영수증 출력.
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void) {
    char menu_names[20][50];
    int menu_prices[20];
    int menu_count = 0;

    FILE *rfp = fopen("menu.txt", "rt");
    if (rfp == NULL) {
        printf("menu.txt 열기 실패!\n");
        return -1;
    }

    char header[100];
    fgets(header, sizeof(header), rfp); // 헤더 스킵

    while (menu_count < 20 && fscanf(rfp, "%s %d", menu_names[menu_count], &menu_prices[menu_count]) == 2) {
        menu_count++;
    }
    fclose(rfp);

    // 포인터 배열을 활용하여 주문 내역 동적 할당
    char *selected_names[100];
    int selected_prices[100];
    int order_count = 0;

    while (1) {
        printf("\n========== MENU ==========\n");
        for (int i = 0; i < menu_count; i++) {
            printf("%d. %s (%d원)\n", i + 1, menu_names[i], menu_prices[i]);
        }
        printf("0. 주문 완료 및 영수증 출력\n");
        printf("선택: ");

        int choice;
        scanf("%d", &choice);

        if (choice == 0) break;
        if (choice < 1 || choice > menu_count) {
            printf("잘못된 번호입니다. 다시 선택하세요.\n");
            continue;
        }

        int idx = choice - 1;
        selected_names[order_count] = (char *)malloc(strlen(menu_names[idx]) + 1);
        strcpy(selected_names[order_count], menu_names[idx]);
        selected_prices[order_count] = menu_prices[idx];
        order_count++;
    }

    // 영수증 출력 (receipt.txt)
    FILE *wfp = fopen("receipt.txt", "wt");
    int total = 0;
    fprintf(wfp, "========= RECEIPT =========\n");
    for (int i = 0; i < order_count; i++) {
        fprintf(wfp, "%-15s %d원\n", selected_names[i], selected_prices[i]);
        total += selected_prices[i];
        free(selected_names[i]); // 메모리 해제
    }
    fprintf(wfp, "---------------------------\n");
    fprintf(wfp, "총 결제금액:    %d원\n", total);
    fclose(wfp);

    printf("\n영수증(receipt.txt)이 발행되었습니다. 총 금액: %d원\n", total);
    return 0;
}
```

### [실습 4] 단어 다중 구분자 분리 및 사전식 정렬
- **요구사항**: `words.txt`에서 문자열을 읽어 구분자(`\t`, `;`, `|`, `,`, 공백)로 단어를 분리 $\rightarrow$ `make_dictionary` 및 `my_strcmp` 함수를 사용해 포인터 배열을 사전순 정렬 $\rightarrow$ `dictionary.txt`에 저장.
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MAX_WORDS 500
#define MAX_LEN 100

int my_strcmp(const char *s1, const char *s2) {
    return strcmp(s1, s2);
}

// 포인터의 주소값만 교환하여 효율적으로 정렬
void make_dictionary(char *words[], int count) {
    for (int i = 0; i < count - 1; i++) {
        for (int j = i + 1; j < count; j++) {
            if (my_strcmp(words[i], words[j]) > 0) {
                char *temp = words[i];
                words[i] = words[j];
                words[j] = temp;
            }
        }
    }
}

int main(void) {
    FILE *rfp = fopen("words.txt", "rt");
    if (!rfp) return -1;

    char buffer[4096];
    char *words[MAX_WORDS];
    int count = 0;

    while (fgets(buffer, sizeof(buffer), rfp) != NULL) {
        // strtok를 이용한 다중 구분자 분리: tab, semicolon, bar, comma, newline, space
        char *token = strtok(buffer, "\t;|, \r\n");
        while (token != NULL && count < MAX_WORDS) {
            words[count] = (char *)malloc(strlen(token) + 1);
            strcpy(words[count], token);
            count++;
            token = strtok(NULL, "\t;|, \r\n");
        }
    }
    fclose(rfp);

    // 정렬 수행
    make_dictionary(words, count);

    // dictionary.txt 저장
    FILE *wfp = fopen("dictionary.txt", "wt");
    for (int i = 0; i < count; i++) {
        fprintf(wfp, "%s\n", words[i]);
        free(words[i]); // 메모리 해제
    }
    fclose(wfp);
    return 0;
}
```

## 6. 시험 및 디버깅 빈출 체크리스트

1. **파일 포인터 NULL 검사**: `fopen()` 후 반드시 `if (fp == NULL)` 검사를 진행했는가?
2. **반드시 `fclose()` 호출**: 파일을 닫지 않으면 버퍼의 내용이 디스크에 온전히 기록되지 않거나 파일 잠금(Lock) 현상이 발생합니다.
3. **`fgets`의 개행 문자(`\n`)**: `fgets`는 `\n`까지 배열에 담으므로 문자열 비교(`strcmp`) 시 `str[strcspn(str, "\r\n")] = '\0';` 처리 필요 여부를 체크하세요.
4. **포인터 배열 정렬 시 데이터 복사가 아닌 주소 교환**: 문자열 자체를 `strcpy`로 옮기는 것보다 `char *temp = arr[i]; arr[i] = arr[j]; arr[j] = temp;` 처럼 포인터만 교환하는 것이 속도 및 메모리 면에서 핵심 평가 요소입니다.
5. **동적 할당 후 `free()`**: `malloc()`을 사용했다면 파일 출력 완료 후 반드시 `free()`를 수행하여 메모리 누수를 방지해야 감점을 피할 수 있습니다.
