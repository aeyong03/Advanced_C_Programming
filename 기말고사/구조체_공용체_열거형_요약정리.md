## 1. 자료형의 발전과 사용자 정의 자료구조

### 1.1 데이터 표현의 진화 과정
- **단일 변수**: 하나의 메모리 공간에 하나의 값만 저장 (`int a;`, `double d;`)
- **배열 (Array)**: **동일한 데이터 타입**의 여러 원소를 연속된 메모리에 나열하여 인덱스로 관리 (`int arr[10];`)
- **구조체 (Structure)**: **서로 다른 데이터 타입**을 하나의 블록으로 묶어 새로운 데이터형(Customizing Data Structure)을 정의
- **클래스 (Class, C++ 등)**: 구조체(변수)에 더해 해당 데이터를 조작하는 **함수(메서드)**까지 하나로 묶어 캡슐화한 객체지향의 기본 단위

### 1.2 왜 구조체(Customizing Data Structure)가 필요한가?
- 컴퓨터 프로그램은 현실 세계의 데이터와 프로세스를 컴퓨터 언어로 모델링하는 것입니다.
- 예를 들어 현실의 "학생"은 **이름(문자열), 학번(정수), 성적(실수)** 등 서로 다른 속성을 동시에 지닙니다.
- 만약 구조체가 없다면 `name[100][20]`, `id[100]`, `score[100]`처럼 여러 개의 독립된 배열로 관리해야 하므로, 데이터 간 연관성이 깨지기 쉽고 함수 전달 및 유지보수가 극히 비효율적입니다.
- **비빔밥 비유**: 여러 가지 재료(당근, 밥, 나물)를 한 그릇에 담아 "비빔밥"이라는 새로운 요리로 취급하듯이, 구조체는 이종(heterogeneous)의 데이터들을 하나의 단위로 묶어 취급합니다.

## 2. 구조체 (Structure) 기본 문법

### 2.1 구조체 정의와 멤버 접근
- 구조체 안에서 정의된 변수를 **멤버 변수(Member Variable)**라고 부릅니다.
- 일반적인 구조체 변수의 멤버에 접근할 때는 **도트(점, `.`) 직접 접근 연산자**를 사용합니다.

```c
struct bibim {
    int carrot;   // 당근 양
    int rice;     // 밥 양
    int egg;      // 달걀 개수
};

int main(void) {
    struct bibim b1; // 구조체 변수 b1 선언
    b1.carrot = 10;  // b1 안의 당근에 접근
    b1.rice = 1;
    b1.egg = 1;
    return 0;
}
```

### 2.2 붕어빵 틀(구조체 형) vs 붕어빵(구조체 변수)
- **구조체 형(Type)**: 메모리에 실체가 없는 설계도(틀)입니다. (크기만 정의됨)
- **구조체 변수(Variable)**: 설계도를 기반으로 메모리에 실제 공간(RAM)이 할당된 인스턴스(붕어빵)입니다.

### 2.3 구조체 선언 방식 3가지

#### ➊ 구조체 형 선언 후 별도 변수 선언 (표준적인 방식)
```c
struct student {
    char name[20];
    int kor;
    int eng;
};

struct student s1; // 선언 시 매번 'struct student'를 명시해야 함
```

#### ➋ 구조체 형 선언과 동시에 변수 선언
```c
struct student {
    char name[20];
    int kor;
    int eng;
} s1, s2; // 구조체 틀 정의 끝 세미콜론 직전에 변수명 기술
```

#### ➌ `typedef`를 이용한 별칭 부여 (가장 권장되는 실무/강의 방식)
`struct student`라는 긴 이름 대신 `Student`라는 단일 식별자로 변수를 선언할 수 있습니다.
```c
typedef struct _student {
    char name[20];
    int kor;
    int eng;
} Student; // struct _student 형을 'Student'로 정의

Student s1; // 'struct' 키워드 없이 깔끔하게 선언 가능
```

### 2.4 구조체 초기화 규칙
- 배열 초기화와 마찬가지로 중괄호 `{ }` 안에 멤버 순서대로 값을 나열합니다.
- **중요 규칙**:
  1. 초기값을 기술하지 않은 멤버 변수는 **0 (문자열인 경우 `\0`, 포인터는 `NULL`)으로 자동 초기화**됩니다.
  2. 초기화 구문을 전혀 쓰지 않고 선언만 한 지역 구조체 변수는 **쓰레기 값(Garbage value)**을 가집니다.

```c
Student s1 = {"홍길동", 90, 95}; // 순서대로 대입
Student s2 = {"이순신", 100};     // eng는 명시하지 않았으므로 0으로 자동 초기화
```

## 3. 구조체 배열과 구조체 포인터

### 3.1 구조체 배열
- 여러 명의 학생 데이터를 다룰 때 사용합니다.
- 메모리 상에 구조체 크기만큼 연속해서 나열됩니다.

```c
Student s[3]; // 학생 3명을 저장하는 구조체 배열
s[0].kor = 90;
s[1].kor = 85;
```

### 3.2 구조체 포인터와 화살표 연산자 (`->`)
- 구조체 변수의 주소를 저장하는 포인터를 **구조체 포인터**라고 합니다.
- 포인터를 통해 멤버에 접근할 때 역참조 `*`를 사용하려면 연산자 우선순위 때문에 반드시 괄호를 쳐야 합니다.
  - `*p.kor` ❌ : `.` 연산자가 `*`보다 우선순위가 높아 `*(p.kor)`로 해석되어 에러 발생!
  - `(*p).kor` ⭕ : 올바른 역참조 표현
  - **`p->kor`** 🌟 : `(*p).kor`의 간결하고 직관적인 단축 표현 (화살표 간접 접근 연산자)

```c
Student s = {"철수", 80, 90};
Student *p = &s;

printf("%s\n", (*p).name); // 괄호 필수
printf("%s\n", p->name);   // 화살표 연산자 (가장 널리 쓰임)
```

### 3.3 구조체와 동적 메모리 할당 (`malloc`)
학생 수가 실행 시점에 결정되는 경우(사용자 입력 등), 동적 할당을 사용합니다.

```c
// 1명 동적 할당
Student *p = (Student *)malloc(sizeof(Student));
p->kor = 100;
free(p);

// N명 동적 할당 (동적 구조체 배열)
int n;
scanf("%d", &n);
Student *arr = (Student *)malloc(sizeof(Student) * n);

for (int i = 0; i < n; i++) {
    // 배열 인덱스 방식 접근
    arr[i].kor = 90;
    // 또는 포인터 연산 방식 접근
    (arr + i)->eng = 95;
}

free(arr); // 사용 후 반드시 해제!
```

## 4. 공용체 (Union)

### 4.1 공용체의 개념 및 구조체와의 비교
- **공용체(`union`)**: 모든 멤버 변수가 **동일한 메모리 시작 위치와 공간을 공유**하는 사용자 정의 자료형입니다.
- **문법**: `struct` 키워드 대신 **`union`** 키워드를 사용합니다.

```c
struct S_Data {
    char ch;  // 1 바이트
    int num;  // 4 바이트
}; // 크기: 패딩 고려 시 약 8 바이트 (각각 별도 메모리)

union U_Data {
    char ch;  // 1 바이트
    int num;  // 4 바이트
}; // 크기: 가장 큰 멤버인 int 크기에 맞춘 4 바이트 (동일 공간 공유)
```

```
[구조체 S_Data 메모리 구조]
+------+-------+-------+-------+
|  ch  | (pad) | (pad) | (pad) |
+------+-------+-------+-------+
|              num             |
+------+-------+-------+-------+
=> 총 8 바이트, ch와 num이 서로 다른 곳에 위치

[공용체 U_Data 메모리 구조]
+------+-------+-------+-------+
|  ch  |                       |
+------+-------+-------+-------+
|              num             |
+------+-------+-------+-------+
=> 총 4 바이트, ch는 num의 첫 1바이트 공간을 공유!
```

### 4.2 공용체의 특징 및 크기 계산
1. **공용체의 크기**: 멤버들 중 **가장 메모리 크기가 큰 멤버의 크기**가 공용체 변수의 크기가 됩니다. (정렬 배수 고려)
2. **동시 사용 불가**: 한 번에 하나의 멤버만 의미 있는 데이터를 가질 수 있습니다. 한 멤버에 값을 대입하면 다른 멤버의 기존 값은 덮어씌워져 훼손됩니다.

### 4.3 공용체는 언제 사용하는가?
1. **메모리 절약**: 여러 정보 중 **배타적으로 딱 하나만 사용**될 때 (예: 사용자의 인증 정보로 `전화번호` 또는 `주민등록번호` 중 하나만 입력받을 때).
2. **이기종 데이터 변환 (Type Punning)**: 하나의 4바이트 정수(`int`)의 각 바이트(`char[4]`)를 개별적으로 읽어 네트워크 패킷이나 하드웨어 레지스터를 제어할 때.

### 4.4 중첩 구조체/공용체 사용 예 (9주차 실습 1)
```c
union Info {
    char phone[15];
    char id_num[15];
};

struct User {
    char name[20];
    union Info info; // 공용체를 구조체 멤버로 선언
};
```

## 5. 열거형 (Enumeration, enum)

### 5.1 열거형 문법과 기본 동작 원리
- **열거형(`enum`)**: 연관된 연속된 정수 상수들에 **사람이 읽기 쉬운 기호화된 이름(이름표)**을 붙여 코드의 가독성을 높이는 문법입니다.
- 기본적으로 첫 번째 항목은 **0**부터 시작하며, 1씩 자동 증가합니다.

```c
enum week {
    SUN, // 0
    MON, // 1
    TUE, // 2
    WED, // 3
    THU, // 4
    FRI, // 5
    SAT  // 6
};
```

### 5.2 명시적 값 지정과 자동 증가 규칙
- 특정 항목에 값을 직접 지정할 수 있습니다.
- 값을 지정하지 않은 항목은 **직전 항목의 값에서 +1** 된 값을 부여받습니다.

```c
enum month {
    JAN = 1, // 1로 시작
    FEB,     // 2
    MAR,     // 3
    APR,     // 4
    MAY = 10,// 10으로 강제 지정
    JUN      // 11 (직전 값 10에서 1 증가)
};
```

### 5.3 열거형과 `switch-case`의 결합
매직 넘버(1, 2, 3...) 대신 의미 있는 식별자를 `case` 레이블에 사용하여 가독성과 유지보수성을 극대화합니다.

```c
enum season { SPRING, SUMMER, FALL, WINTER };

enum season cur = SPRING;
switch (cur) {
    case SPRING: printf("따뜻한 봄입니다.\n"); break;
    case SUMMER: printf("뜨거운 여름입니다.\n"); break;
    case FALL:   printf("선선한 가을입니다.\n"); break;
    case WINTER: printf("추운 겨울입니다.\n"); break;
}
```

## 6. 실전 실습 과제 구현 및 완벽 분석 (8주차 & 9주차)

### [8주차 실습 1] 구조체를 활용한 평점 계산기
- **핵심 목표**: 이전 7주차의 단순 변수들을 `Subject`라는 구조체로 묶어 파일(`grade.txt`)로부터 읽어 평점을 계산.
```c
#include <stdio.h>
#include <string.h>

typedef struct {
    char subject[50];
    int credit;
    char grade[5];
    double score;
} Subject;

int main(void) {
    FILE *fp = fopen("grade.txt", "rt");
    if (fp == NULL) {
        printf("grade.txt 파일 열기 실패!\n");
        return -1;
    }

    Subject s;
    double total_score = 0.0;
    int total_credit = 0;

    printf("과목명\t\t과목별 점수\n");
    printf("---------------------------\n");

    char temp[100];
    fgets(temp, sizeof(temp), fp); // 첫 행 헤더 스킵

    while (fscanf(fp, "%s %d %s", s.subject, &s.credit, s.grade) == 3) {
        double grade_point = 0.0;

        if (strcmp(s.grade, "A+") == 0) grade_point = 4.5;
        else if (strcmp(s.grade, "A0") == 0) grade_point = 4.0;
        else if (strcmp(s.grade, "B+") == 0) grade_point = 3.5;
        else if (strcmp(s.grade, "B0") == 0) grade_point = 3.0;
        else if (strcmp(s.grade, "C+") == 0) grade_point = 2.5;
        else if (strcmp(s.grade, "C0") == 0) grade_point = 2.0;
        else if (strcmp(s.grade, "D+") == 0) grade_point = 1.5;
        else if (strcmp(s.grade, "D0") == 0) grade_point = 1.0;
        else grade_point = 0.0;

        s.score = s.credit * grade_point;
        printf("%-15s\t%.1f\n", s.subject, s.score);

        total_score += s.score;
        total_credit += s.credit;
    }

    if (total_credit > 0) {
        printf("---------------------------\n");
        printf("총 평점: %.2f\n", total_score / total_credit);
    }

    fclose(fp);
    return 0;
}
```

### [8주차 실습 3] 학생별 & 과목별 평균 관리 프로그램
- **핵심 목표**: 학생들의 개별 성적(`Student`)을 동적 배열로 관리하고, 요약 통계(`Summary`) 구조체를 활용하여 파일 `average_strudent.txt`에 저장.
```c
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    char name[20];
    int kor;
    int eng;
    float avg;
} Student;

typedef struct {
    float kor_avg;
    float eng_avg;
    float total_avg;
} Summary;

int main(void) {
    int count;
    printf("학생 수 입력: ");
    if (scanf("%d", &count) != 1 || count <= 0) return -1;

    Student *s = (Student *)malloc(sizeof(Student) * count);
    if (s == NULL) return -1;

    int total_kor = 0;
    int total_eng = 0;
    float sum_student_avg = 0.0f;

    for (int i = 0; i < count; i++) {
        printf("%d번째 학생 이름, 국어 점수, 영어 점수 입력: ", i + 1);
        scanf("%s %d %d", (s + i)->name, &(s + i)->kor, &(s + i)->eng);

        (s + i)->avg = ((s + i)->kor + (s + i)->eng) / 2.0f;

        total_kor += (s + i)->kor;
        total_eng += (s + i)->eng;
        sum_student_avg += (s + i)->avg;
    }

    Summary summary;
    summary.kor_avg = (float)total_kor / count;
    summary.eng_avg = (float)total_eng / count;
    summary.total_avg = sum_student_avg / count;

    FILE *fp = fopen("average_strudent.txt", "wt");
    if (fp == NULL) {
        free(s);
        return -1;
    }

    fprintf(fp, "-- 학생 성적 목록 --\n");
    for (int i = 0; i < count; i++) {
        fprintf(fp, "이름: %s | 국어: %d | 영어: %d | 평균: %.2f\n",
                (s + i)->name, (s + i)->kor, (s + i)->eng, (s + i)->avg);
    }

    fprintf(fp, "\n-- 전체 요약 --\n");
    fprintf(fp, "국어 과목 평균: %.2f\n", summary.kor_avg);
    fprintf(fp, "영어 과목 평균: %.2f\n", summary.eng_avg);
    fprintf(fp, "모든 학생 총 평균: %.2f\n", summary.total_avg);

    fclose(fp);
    free(s);
    printf("average_strudent.txt에 결과를 성공적으로 저장했습니다.\n");
    return 0;
}
```

### [9주차 실습 3] 도서관 도서 대여 프로그램
- **핵심 목표**: `books.txt` 파일로부터 도서 정보를 파싱하여 `booklist` 배열을 초기화하고, 사용자로부터 ID를 입력받아 재고를 실시간 차감 및 대여 목록(`rentlist`)에 반영.
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define MAX_BOOKS 50

typedef struct {
    int id;
    char title[100];
    int count;
} Book;

void initial_booklist(Book booklist[], int *book_cnt);
void manage_booklist(Book booklist[], int book_cnt, Book rentlist[], int *rent_cnt, int req_id);
void print_booklist(Book booklist[], int book_cnt);

int main(void) {
    Book booklist[MAX_BOOKS];
    Book rentlist[MAX_BOOKS];
    int book_cnt = 0;
    int rent_cnt = 0;
    int req_id;

    initial_booklist(booklist, &book_cnt);
    if (book_cnt == 0) {
        printf("불러온 도서 정보가 없습니다.\n");
        return -1;
    }

    print_booklist(booklist, book_cnt);

    while (1) {
        printf("\n대여를 원하는 도서의 ID를 입력하세요 (목록 보기: -1, 종료: 0) : ");
        if (scanf("%d", &req_id) != 1) {
            printf("[오류] 숫자(도서 ID)만 입력해주세요.\n");
            while (getchar() != '\n'); // 입력 버퍼 비우기
            continue;
        }

        if (req_id == 0) {
            printf("도서 대여 프로그램을 종료합니다.\n");
            break;
        } else if (req_id == -1) {
            print_booklist(booklist, book_cnt);
            continue;
        }

        manage_booklist(booklist, book_cnt, rentlist, &rent_cnt, req_id);
    }

    return 0;
}

void print_booklist(Book booklist[], int book_cnt) {
    printf("\n==================== 현재 보유 도서 목록 ====================\n");
    printf("%-10s %-38s %s\n", "도서 ID", "도서 제목", "보유 권수");
    printf("-------------------------------------------------------------\n");
    for (int i = 0; i < book_cnt; i++) {
        printf("%-10d %-38s %d권\n", booklist[i].id, booklist[i].title, booklist[i].count);
    }
    printf("=============================================================\n");
}

void initial_booklist(Book booklist[], int *book_cnt) {
    FILE *fp = fopen("books.txt", "rt");
    if (fp == NULL) {
        printf("books.txt 파일 열기 실패!\n");
        return;
    }

    char line[256];
    fgets(line, sizeof(line), fp); // 헤더 스킵

    int idx = 0;
    while (idx < MAX_BOOKS && fgets(line, sizeof(line), fp) != NULL) {
        int len = (int)strlen(line);
        while (len > 0 && isspace((unsigned char)line[len - 1])) {
            line[len - 1] = '\0';
            len--;
        }
        if (len == 0) continue;

        // 끝부분의 권수(숫자) 파싱
        int num_start = len - 1;
        while (num_start >= 0 && isdigit((unsigned char)line[num_start])) {
            num_start--;
        }
        num_start++;

        booklist[idx].count = atoi(&line[num_start]);

        // 제목 부분 추출
        int title_end = num_start - 1;
        while (title_end >= 0 && isspace((unsigned char)line[title_end])) {
            line[title_end] = '\0';
            title_end--;
        }

        strncpy(booklist[idx].title, line, sizeof(booklist[idx].title) - 1);
        booklist[idx].title[sizeof(booklist[idx].title) - 1] = '\0';
        booklist[idx].id = 101 + idx; // ID는 101번부터 부여
        idx++;
    }

    *book_cnt = idx;
    fclose(fp);
}

void manage_booklist(Book booklist[], int book_cnt, Book rentlist[], int *rent_cnt, int req_id) {
    int found_idx = -1;
    for (int i = 0; i < book_cnt; i++) {
        if (booklist[i].id == req_id) {
            found_idx = i;
            break;
        }
    }

    if (found_idx == -1) {
        printf("[알림] 해당 ID(%d)의 도서는 보유하지 않은 도서입니다.\n", req_id);
        return;
    }

    if (booklist[found_idx].count <= 0) {
        printf("[알림] '%s' 도서는 현재 보유 도서가 모두 대여되었습니다.\n", booklist[found_idx].title);
        return;
    }

    // 재고 차감 및 대여 목록 반영
    booklist[found_idx].count--;

    int rent_found = -1;
    for (int i = 0; i < *rent_cnt; i++) {
        if (rentlist[i].id == req_id) {
            rent_found = i;
            break;
        }
    }

    if (rent_found != -1) {
        rentlist[rent_found].count++;
    } else {
        rentlist[*rent_cnt].id = booklist[found_idx].id;
        strcpy(rentlist[*rent_cnt].title, booklist[found_idx].title);
        rentlist[*rent_cnt].count = 1;
        (*rent_cnt)++;
    }

    printf("[대여 완료] '%s' 도서가 대여되었습니다. (남은 권수: %d권)\n",
           booklist[found_idx].title, booklist[found_idx].count);
}
```

## 7. 시험 및 코딩 테스트 빈출 체크리스트

1. **연산자 우선순위 주의**:
   - `*p.kor`는 `*(p.kor)`로 컴파일 에러! 반드시 `(*p).kor` 또는 `p->kor`를 사용할 것.
2. **구조체 복사(대입 연산)의 한계**:
   - `s1 = s2;`는 모든 멤버의 바이트 단위 복사(Shallow Copy, 얕은 복사)가 일어납니다.
   - 만약 멤버에 `char *`와 같은 포인터가 들어있다면 주소값만 복사되므로, 한쪽에서 `free()`를 하면 다른 쪽도 댕글링 포인터(Dangling Pointer)가 됩니다.
3. **구조체 메모리 패딩(Memory Padding / Alignment)**:
   - 컴파일러는 CPU의 메모리 접근 속도 향상을 위해 멤버 사이 또는 끝에 빈 패딩 바이트를 삽입합니다.
   - 예: `struct { char c; int n; };`의 크기는 $1 + 4 = 5$ 바이트가 아니라, 4바이트 정렬에 의해 **8 바이트**가 됩니다.
4. **공용체(`union`) 크기 계산**:
   - 멤버들 중 **가장 큰 자료형의 크기**를 기준으로 정렬 배수가 결정됩니다.
   - 예: `union { char str[10]; int n; };`의 크기는 가장 큰 10바이트 이상이면서 `int`(4바이트)의 배수인 **12 바이트**가 됩니다.
5. **동적 할당 후 `free()` 누락 여부**:
   - 구조체 포인터에 `malloc()`을 사용했다면 프로그램 종료 전 반드시 `free()`를 호출해야 메모리 누수 감점을 피할 수 있습니다.
